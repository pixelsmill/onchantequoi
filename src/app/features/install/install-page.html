iPhone

1. Ajouter l'app à l'écran d'accueil

  1. Ouvrez le lien de la chorale dans Safari.
  2. Touchez le bouton Partager (le carré avec une flèche vers le haut).
  3. Choisissez « Sur l'écran d'accueil », puis Ajouter.
  4. Au premier lancement, l'app peut redemander le lien : copiez-le avant (bouton ci-dessous), puis touchez « Coller le lien ».

2. Envoyer les audios reçus sur WhatsApp

Sur iPhone, une app web ne peut pas recevoir de partage. On passe donc par un raccourci « Envoyer à la Chorale », à installer une seule fois.

  1. Dans WhatsApp, faites un appui long sur l'audio, puis touchez Transférer.
  2. Touchez l'icône Partager (le carré avec une flèche vers le haut).
  3. Choisissez « Envoyer à la Chorale » (touchez Plus si vous ne le voyez pas).
  4. La première fois, iOS demande d'autoriser la connexion : touchez Toujours autoriser.
  5. Une notification confirme l'envoi : l'audio attend dans « À classer ».

Sans le raccourci : enregistrez l'audio dans Fichiers depuis WhatsApp, puis utilisez le bouton Déposer de l'app.

Créer le raccourci (une seule fois, pour l'organisateur)
  1. Ouvrez l'app Raccourcis, touchez + et nommez-le « Envoyer à la Chorale ».
  2. Ajoutez une action Texte et collez-y l'adresse d'envoi ci-dessous.
  3. Dans les détails du raccourci (ⓘ), activez « Dans la feuille de partage », types Fichiers et Supports uniquement.
  4. Ajoutez « Répéter chaque élément » sur l'entrée du raccourci.
  5. Dans la boucle : « Obtenir le contenu de l'URL » avec le Texte comme URL, En afficher plus : méthode POST, en-tête X-Nom = Répéter l'élément › Nom, Demander le corps : Fichier = Répéter l'élément.
  6. Toujours dans la boucle : « Afficher la notification » avec le Contenu de l'URL.
  7. Testez depuis WhatsApp, puis partagez-le : Partager → Copier le lien iCloud. Postez ce lien dans le groupe (et collez-le dans shortcutUrl de src/app/config.ts pour qu'il apparaisse ici).

Recette détaillée : docs/raccourci-iphone.md dans le projet.

Android

1. Installer l'app

@if (pwa.canInstall()) { } @else {
  1. Ouvrez le lien de la chorale dans Chrome.
  2. Touchez le menu ⋮ en haut à droite.
  3. Choisissez « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
}

2. Envoyer les audios reçus sur WhatsApp

  1. Dans WhatsApp, sélectionnez un ou plusieurs audios (appui long).
  2. Touchez Partager, puis choisissez Chorale.
  3. L'app s'ouvre et envoie les audios dans « À classer ».

L'app doit être installée pour apparaître dans la liste de partage.

Ordinateur
  1. Enregistrez les audios depuis WhatsApp (Web ou application).
  2. Glissez-les n'importe où sur la page de l'app, ou utilisez le bouton Déposer.
  3. Ils arrivent dans « À classer ».
